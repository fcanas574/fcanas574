# Hi, I'm Felipe Cañas

I build mobile apps and Python tools for everyday problems, from organizing coursework to managing campus parking and identifying phishing messages.

Based in El Salvador. My projects combine app development, API integrations, and applied machine learning.

## Selected projects

| Project | What it does | Technologies |
| --- | --- | --- |
| [UniPark](https://github.com/fcanas574/QR-parking-students) | Campus parking management with separate apps for drivers and security staff, QR scanning, and offline support for guards. | TypeScript, React Native, Expo, Supabase, Clerk |
| [NotionSync](https://github.com/fcanas574/NotionSync) | A desktop app that syncs Canvas LMS assignments to Notion and helps organize study time. | Python, PyQt6, Canvas API, Notion API |
| [Betinho8](https://github.com/fcanas574/Betinho8) | A Spanish-language phishing detection project developed for the Key Institute Hackathon '25, using BETO and a FastAPI prediction endpoint. | Python, BETO, FastAPI |
| [GAPC](https://github.com/fcanas574/GAPC_AppKeyWeek2) | An app for tracking loans in community savings groups, designed for people with limited literacy. | Python, JavaScript, SQLite |
